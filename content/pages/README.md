# Страницы конспектов

Фотографии страниц конспектов по физике (201 страница, файлы `*.webp`) не публикуются в репозитории.
Здесь только их список — `pages.txt`: по нему собирается учебная база (`npm run content:build`).

Без фотографий приложение работает полностью; на экране «Страница конспекта» вместо фото показывается пояснение.
Чтобы фото были в приложении, положите файлы `*.webp` из `pages.txt` в эту папку и пересоберите приложение.
