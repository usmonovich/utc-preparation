## o01 (низ) «Оптика»
- Оптика — это раздел физики, который изучает физические процессы, связанные с распространением света. Оптика делится на три части: ① геометрическая оптика; ② волновая оптика; ③ физическая оптика.

## o02 «Геометрическая оптика»

- **Закон преломления.** Преломление света происходит, когда луч света переходит из одной среды в другую, то есть пересекает границу раздела двух сред. Рисунок: среды $n_1$ (сверху) и $n_2$, угол падения α, отражённый луч под α, преломлённый луч под β.
- $\frac{\sin\alpha}{\sin\beta} = \frac{n_2}{n_1}$ (в рамке) — закон Снеллиуса.

## o08 «Дисперсия»
- Монохроматический свет — это набор лучей с одинаковым значением частоты. Полихроматический свет — это набор лучей с разными значениями частоты.
- В природе в основном источники света распространяют полихроматический свет. Лазер является источником монохроматического света. Естественный белый свет Солнца тоже является полихроматическим светом. Естественный белый свет можно разложить на отдельные лучи, то есть цвета, с помощью эффекта дисперсии.
- Дисперсию можно получить с помощью дифракционной решётки, треугольной призмы и водяной капли.

- * плоско-выпуклая; плоско-вогнутая: $R_1 = R$, $R_2 = \infty$ (плоская). $\frac1F = \left(\frac{n_л - n_с}{n_с}\right)\frac1R$ (в рамке); $D = \left(\frac{n_л - n_с}{n_с}\right)\frac1R$ (в рамке).
- ** $n_с = 1$: $\frac1F = \frac{n_л - 1}{R}$ (в рамке); $D = \frac{n_л - 1}{R}$ (в рамке).
- **Правило!** 1) Выпуклая линза: $R_1, R_2 > 0$. 2) Вогнутая линза: $R_1, R_2 < 0$. 3) Собирающая линза: F, D > 0. 4) Рассеивающая линза: F, D < 0.
- **Вывод:** выпуклая → собирающая; вогнутая → рассеивающая. * При $n_л < n_с$ (в рамке): выпуклая → рассеивающая; вогнутая → собирающая.
- **Система линз.** Рисунок: две линзы (оптические силы $D_1$, $D_2$, фокусы $F_1$, $F_2$) на расстоянии l. $D = D_1 + D_2 - lD_1D_2$; $\frac1F = \frac{1}{F_1} + \frac{1}{F_2} - \frac{l}{F_1F_2}$ (в рамке).

## o20
- * при l = 0: $D = D_1 + D_2$; $\frac1F = \frac{1}{F_1} + \frac{1}{F_2}$ (в рамке).
- Рисунок: две собирающие линзы, параллельный пучок сходится в общем фокусе и выходит параллельным. $l = F_1 + F_2$ (в рамке) — две фокальные плоскости лежат друг на друге.
- **Глаз** (дата 1.04.25). Человеческий глаз тоже является оптической системой, где расположена собирающая линза; с помощью этой линзы в сетчатке глаза возникает действительное, перевёрнутое, уменьшенное изображение всех тел.
