## a01 «Атомная физика. Модель Резерфорда»
- Резерфорд предложил свою модель, опираясь на свой опыт. В своём опыте он направил пучок заряженных частиц в направлении тонкой металлической пластины (алюминиевая фольга). ⚠ ЗАМЕЧАНИЕ: в опыте Резерфорда (Гейгера–Марсдена) использовали α-частицы и тонкую золотую фольгу.
- Под воздействием электрического поля ядра частицы отклонялись на большие углы. ⚠ ЗАМЕЧАНИЕ: на большие углы отклонялась лишь малая доля частиц, большинство проходило почти без отклонения.
- [Рисунок: столбик кружков-частиц слева, большой круг — ядро/атом.]
- По модели Резерфорда: атом — это частица, состоящая из плотного положительно заряженного ядра, вокруг которого на больших расстояниях вращаются электроны, подобно планетам вокруг Солнца. Электроны движутся вокруг ядра по орбитам за счёт электростатического притяжения к ядру.
- **Постулаты Бора.** ① Атом может находиться только в определённых (стационарных) энергетических состояниях, при которых электроны движутся по разрешённым орбитам без излучения энергии.

## a04
- Изотопы — это ядра с одинаковым количеством протонов.
- Изобары — это ядра с одинаковым количеством нуклонов.
- Изотоны — это ядра с одинаковым количеством нейтронов.
- $^1_1H$, $^2_1H$, $^3_1H$; $^{16}_8O$, $^{17}_8O$, $^{18}_8O$ — изотопы (Z обведено красным).
- $^{59}_{27}Co$, $^{59}_{28}N$ — изобары (A обведено). ⚠ ОПИСКА: элемент с Z = 28 — никель Ni; N — азот (Z = 7).
- $^3_1H$, $^4_2He$ — изотоны (у обоих по 2 нейтрона).
- **Атомная структура.** [Рисунки:] $^{17}_8O$, $q = 0$ — 8 электронов вокруг ядра; $^{12}_6C$, $q = +e$ — 5 электронов; $^{11}_5B$, $q = -2e$ — нарисованы 2 электрона. ⚠ ЗАМЕЧАНИЕ: при $q = -2e$ у бора (5 протонов) должно быть 7 электронов; рисунок, видимо, не закончен.

## a05 «Энергия связи ядра»
- Сила, которая возникает только между двумя нуклонами, называется ядерной силой. Данная сила может возникнуть между протон–протоном, протон–нейтроном и нейтрон–нейтроном. Основное условие возникновения ядерных сил — расстояние между нуклонами должно быть в пределах $10^{-15}$ м.
- [Рисунок: 2 протона и 2 нейтрона по отдельности — «4 а.е.м»; они же вместе в ядре — «3,9 а.е.м».]
- $E_{связи} = \Delta mc^2$; $\Delta E = \Delta mc^2$ (в рамке). Δm — дефект массы.
- $\Delta m = Z\cdot m_p + (A - Z)m_n - m_{ядра}$ (в рамке).
- Энергия связи — это необходимая энергия для того, чтобы разделить ядро на отдельные нуклоны.
- Удельная энергия связи — это необходимая энергия для того, чтобы отделить один нуклон от ядра, или энергия связи одного нуклона. ⚠ ЗАМЕЧАНИЕ: по формуле ниже это средняя энергия связи на один нуклон.
- ε — удельная энергия связи: $\varepsilon = \frac{E_{связи}}{A}$ [эВ/нуклон] (в рамке).

## a06 «Основные частицы»
- $^1_1p$ — протон / $^1_1H$ — ядро водорода.
- $^1_0n$ — нейтрон.
- $^0_{-1}e^-$ — электрон / $^0_{-1}\beta^-$ — частица.
- $^0_{+1}e^+$ — позитрон / $^0_{+1}\beta^+$ — частица.
- $^4_2\alpha$ — частица / $^4_2He$ — ядро гелия.
- $^0_0\gamma$ — луч / ЭМВ.
- $^2_1H$ — «дайтрон» / дейтерий. ⚠ ОПИСКА: дейтрон.
- $^3_1H$ — тритон / тритий.
- **Ядерные реакции.** $^{A_1}_{Z_1}X + ^{A_2}_{Z_2}Y \to ^{A_3}_{Z_3}K + ^{A_4}_{Z_4}L$; $A_1 + A_2 = A_3 + A_4$; $Z_1 + Z_2 = Z_3 + Z_4$.
- \* Бомбардировка: $^{232}_{90}Th + ^1_0n \to ^{108}_{47}Ag + ^{73}_{32}Ge + ^1_1p + ^4_2\alpha + ^{47}_{8}O$ (последнее ядро дописано красным — найдено по законам сохранения; символ тория написан похоже на «Tn» [?]). ⚠ ЗАМЕЧАНИЕ: числа сходятся (233 = 233, 90 = 90), но изотопа кислорода с A = 47 не существует — это учебное упражнение.
- Если в процессе реакции масса ядер увеличивается, то в этой реакции энергия поглощается, и такая реакция называется эндотермической реакцией. Если в процессе реакции масса ядер уменьшается, то в этой реакции энергия (теплота) выделяется, и такая…

## a07
- …реакция называется экзотермической реакцией.
- **Радиоактивность.** Радиоактивность — это способность некоторых тяжёлых ядер, которая связана с самопроизвольным распадом. Радиоактивное ядро в процессе радиоактивного распада распадается, выделяя частицы спонтанным образом, то есть без внешнего воздействия. ⚠ ЗАМЕЧАНИЕ: радиоактивны не только тяжёлые ядра (например, радиоуглерод).
- ① α-распад: $^A_ZX \to ^4_2\alpha + ^{A-4}_{Z-2}Y$. [Клетки таблицы Менделеева: элемент сдвигается на 2 клетки влево, «−2».]
- ② а) β⁻-распад: $^A_ZX \to ^0_{-1}e^- + ^A_{Z+1}Y + \tilde\nu$; $\tilde\nu$ — антинейтрино. [Сдвиг на 1 клетку вправо, «+1».]
  б) β⁺-распад: $^A_ZX \to ^0_{+1}e^+ + ^A_{Z-1}Y + \nu$; ν — нейтрино. [Сдвиг на 1 клетку влево, «−1».]
- ③ γ-распад: $^A_ZX \to ^0_0\gamma + ^A_ZX$. [Элемент остаётся в своей клетке.] ⚠ ЗАМЕЧАНИЕ: γ-квант испускает ядро в возбуждённом состоянии ($^A_ZX^*$).

## a08 «Закон радиоактивного распада»
- [Рисунок: квадрат, разделённый пополам, затем ещё пополам — подписи T, 2T, 3T, 4T: за каждый период остаётся половина.]
- $N(t) = N_0\cdot2^{-\frac tT}$ (в рамке). T — период полураспада; $N_0$ — количество начальных р.а.я. (радиоактивных ядер); $N(t)$ — количество нераспавшихся р.а.я.; t — время.
- $\Delta N = N_0 - N$; $\Delta N = N_0\left(1 - 2^{-\frac tT}\right)$ (в рамке) — количество распавшихся р.а.я.
- Активность — это число радиоактивных распадов за единицу времени: $A = \frac{\Delta N}{\Delta t}$ (в рамке); $A = \frac{N_0}{T}\cdot2^{-\frac tT}\ln2$ (в рамке).
- $\lambda = \frac{\ln2}{T}$ (в рамке) — р.а. постоянная.
- $\tau = \frac{T}{\ln2}$ (в рамке) — время средней жизни.
- $A = \lambda N$; $A_0 = \lambda N_0$; $A(t) = A_0\cdot2^{-\frac tT}$.
