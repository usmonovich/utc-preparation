# Как добавлять новые учебные файлы

Конвейер: файл → страницы → распознавание → структурирование → проверка → утверждение.

1. **Страницы.** `python3 tools/import/pdf_to_pages.py новый.pdf content/pages-new <префикс>` — режет развороты, готовит изображения для приложения и для распознавания. Печатает SHA-256 (защита от повторного импорта). Префикс — одна латинская буква, своя для каждого файла: p — механика, m — молекулярная физика, h — фото «Влажность воздуха», c — электричество, e — магнетизм и колебания, o — оптика, d — фото «Дифракция», a — атомная и ядерная физика (в интерфейсе: «м», «вл», «эл», «мг», «оп», «дф», «ат»; ссылки вида «стр. c03» в текстах подсказок показываются так же). Новый префикс нужно добавить в `sourceFiles` (`pagePrefix`) в `00-structure.yaml` и в подписи страниц `src/domain/page-label.ts`.
2. **Порядок.** Страницы и записи идут в порядке файлов из `sourceFiles`, а разделы и подразделы — в порядке списков `sections` и `subsections`. Чтобы поставить новый материал перед уже загруженным (например, электричество перед оптикой), вставьте его источник и подразделы выше в этих списках; номер YAML-файла влияет только на порядок тем внутри одного подраздела.
3. **Распознавание.** Рукопись: `ANTHROPIC_API_KEY=... node tools/import/transcribe.mjs content/pages-new/ocr > content/transcript/новый.md`. Печатный текст: `pdftotext` или Tesseract с русским языком. Проверьте транскрипт по фото: места `[?]` и `⚠` — обязательно.
4. **Структурирование.** Создайте `content/src/NN-<подраздел>.yaml` (один файл — один подраздел) по образцу существующих файлов: темы, теория, формулы (`sym` — ключи из словаря в `00-structure.yaml`), примеры, вопросы. У каждой записи — `src: pXX`. Вопросы, которых нет в источнике, — это сгенерированные вопросы: они автоматически получают статус «на проверке».
5. **Проверка.** `npm run content:build` — валидатор остановит сборку при ошибке: несуществующая страница, неотрисовываемая формула, неизвестное обозначение, неверный ответ, расхождение числового ответа с выражением `check`, дубль.
6. **Утверждение.** Соберите приложение, откройте Админ-панель → Проверка: сверьте записи с фото страницы и утвердите. Затем «Публикация». Решения, сделанные в артефакте claude.ai, хранятся в его базе; чтобы они попали в сборку приложения, их переносят в `content/review/decisions.json` (`id → {status, hash}`). Сборщик применяет решение, только если запись не менялась после проверки (совпадает хеш); изменённые записи снова идут на проверку.

Правила: не добавлять знаний не из конспекта без разрешения владельца. Если владелец разрешил дополнить пробел из интернета (как 20.10.2026), у записи ставится `web: [{ title, url }]` — ссылки https на источники, а `src` указывает место пробела в конспекте; у темы, целиком составленной по интернету, `web` задаётся на уровне темы. Такие записи показываются с пометкой «из интернета» и проходят проверку как остальные; новые записи — только в конец списков темы; ошибки источника — в `errata`, оригинал не исправлять. У каждого замечания: `target` — к чему оно (какая формула, определение, подпись), `original` — как в конспекте, `issue` — что не так, `suggestion` — конкретно, чем заменить или что дописать (не «уточнить»), `todo` — что нужно от администратора, если решение зависит от того, что было на занятии; без `target` сборка с `--strict` не проходит. Замечания показываются прямо под записью в очереди проверки и в редакторе; новые записи добавлять **в конец** списков темы (ID формируются по позиции) или задавать `id:` явно — так сохраняется история результатов.

**Анимированные рисунки.** Рисунок — файл `content/figures/<id>.svg` (их создаёт `python3 tools/figures/make_figures.py`), подключается к блоку теории полем `fig: <id>`; код рисунков лежит по разделам в `tools/figures/figs_*.py`, общие функции — в `figlib.py` (`_x` в подписи даёт нижний индекс). Цвета — только через классы `s-*`, `f-*`, `t-*` (их задаёт `styles.css`, поэтому работает тёмная тема); все `id` внутри файла начинаются с `<id>-`; скрипты, обработчики событий и внешние ссылки запрещены — сборщик остановится.

## Математика (UTC Preparation)

Математика — отдельная учебная база: `content/math/src/*.yaml` → `content/math/pack.json`, отчёт — `docs/09-math-import-report.md`. Источник порядка тем — книга «Математика. Сборник тестовых заданий для абитуриентов» (две части).

1. **Оглавление.** Пункты книги записаны в `tools/math/toc.py` (номер, заголовок, первая страница). `python3 tools/math/toc.py` печатает блоки `subsections` и `plan` для `content/math/src/00-structure.yaml`. Страницы — печатная нумерация книги, сквозная для обеих частей: `b005` … `b315`. Изображения страниц книги в приложение не встраиваются (авторское право).
2. **Наполнение по порядку.** Где продолжить, написано в начале `docs/09-math-import-report.md` («Где продолжить»). Одна глава — один файл `content/math/src/NN-<глава>.yaml` с `subsection: ma-1-…`. Тема получает `id` вида `ma-1-2-3` (по номеру пункта) и поля: `num`, `pages`, `book.place` и `book.summary` (место и краткое описание книги), `stage` (`extracted` → `prepared` → `needs-check` → `verified`), `stageNote`, `sourcesChecked` (дата проверки источников) и `web` — список дополнительных источников (`title`, `org`, `url`, `checked`, при неполном доступе — `note`).
3. **Содержание темы.** Теория — своими словами по источникам, без копирования. Формулы — с `meaning` (обозначения), `cond` (условия), `use` (когда и почему применять), `variants` (преобразования), `limits` (ограничения). Примеры — `given`, `find`, `method`, `steps`, `check`, `answer` (не меньше трёх на тему). Задачи — `cat: problem` с `sol: { method, steps, check, answer }`; у числовых — независимое выражение `check`. Задания книги не переносятся; все задания составлены по материалам темы и помечены так в приложении.
4. **Проверка.** `npm run content:build:math -- --strict` и `npx tsx --test tests/unit/math.test.ts`: в тесте каждое утверждение теории проверяется перебором или точной арифметикой, ответы примеров пересчитываются. Пункт, где есть сомнение или расхождение источников, получает `stage: needs-check` и `stageNote` с описанием.
5. **Утверждение** — в админ-панели предмета «Математика» (`#/m/admin`), так же, как у физики. PIN администратора общий для обоих предметов.
