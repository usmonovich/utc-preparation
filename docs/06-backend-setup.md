# Подключение Supabase

Без сервера приложение полностью работает на устройстве. Сервер нужен для входа, синхронизации между устройствами и публикации учебной базы без выпуска обновления.

1. Создайте проект на supabase.com (бесплатный тариф подходит для старта).
2. SQL Editor → вставьте и выполните по очереди `supabase/migrations/0001_schema.sql` и `supabase/migrations/0002_subjects.sql`. Миграция 0002 (второй предмет — математика) только добавляет столбцы `subject` (по умолчанию `'physics'`) и обновляет функцию публикации; её можно применять и к базе, где физика уже опубликована, — данные физики не меняются (проверено тестом `tests/db/subjects-test.sql`).
3. Authentication → Providers → Email: включите; задайте минимальную длину пароля 8.
4. Зарегистрируйтесь в приложении своим email, затем назначьте себя администратором (SQL Editor):
   ```sql
   update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'ваш@email');
   ```
5. Соберите приложение с параметрами из Project Settings → API:
   ```bash
   SUPABASE_URL=https://xxxx.supabase.co SUPABASE_ANON_KEY=eyJ... npm run build
   ```
   Ключ `service_role` в приложение **не добавляйте никогда**.
6. Админ-панель → Публикация → «Опубликовать на сервере». Студенты получат версию с утверждёнными вопросами. Физика и математика публикуются отдельно — из админ-панели своего предмета; каждая версия помечена предметом.

## Безопасность

- Все таблицы под RLS: студент видит только утверждённые материалы и только свой прогресс; администратор — всё, кроме чужого прогресса.
- Повысить себе роль через API нельзя (проверено тестом `tests/db`).
- Удаление аккаунта (`delete_my_account`) каскадом удаляет все данные пользователя на сервере.

## Резервное копирование и восстановление

- **Учебная база:** каждая публикация сохраняется в `content_versions` (полный пакет). Дополнительно: Админ-панель → Публикация → «Экспорт пакета» и храните файл вместе с `content/src`.
- **Правки администратора на устройстве:** «Сохранить копию» / «Восстановить».
- **Вся БД:** Database → Backups (на платном тарифе — ежедневно) или вручную: `pg_dump "$DATABASE_URL" > backup.sql`; восстановление: `psql "$DATABASE_URL" < backup.sql`.
- **Прогресс студента:** Настройки → Экспорт/Импорт прогресса.
