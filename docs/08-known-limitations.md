# Известные ограничения (UTC Preparation, версия 1.1)

1. **Стек.** Вместо Flutter — React + Capacitor (обоснование в ТЗ, п. 3). Нативные проекты Android/iOS не созданы в среде разработки: нет Android SDK, macOS и доступа к пакетам. Команды — в `05-release-guide.md`.
2. **Вопросы сгенерированы.** В конспектах нет готовых тестов; все 1141 вопрос (по конспектам и по материалу, дополненному из интернета) составлены по конспектам и имеют статус «на проверке». До утверждения в админ-панели студентам тесты недоступны.
3. **Распознавание всех файлов** выполнено вручную по изображениям; для новых рукописных файлов есть скрипт `transcribe.mjs`, но он не запускался (нет ключа API). Tesseract для рукописи непригоден, а русского языкового пакета в среде не было.
4. **Серверный импорт.** Загрузка файла в админ-панели проверяет и регистрирует файл; распознавание на сервере (Edge Function) не реализовано — используется конвейер `tools/import` на компьютере.
5. **Синхронизация и вход** написаны, но не проверены на живом Supabase. Удаление закладки на одном устройстве может вернуться при синхронизации с другим (нет «надгробий»).
6. **ИИ-ассистент** (п. 12 ТЗ, необязательный) не реализован; основные режимы работают без ИИ.
7. **Ввод формулы как ответа** не реализован: надёжная проверка формул не гарантирована. Вместо него — вопросы «выбор формулы».
8. **Уровни сложности** не введены: конспект не даёт для них оснований.
9. **Шрифты** загружаются с Google Fonts; без интернета используются системные (вид немного меняется). Для полностью офлайн-вида скачайте Golos Text, Unbounded, JetBrains Mono в `dist/fonts`.
10. **Админ-панель и PIN.** Админ-панель есть только в личной версии владельца (опубликованная страница в Claude). В сборке для магазинов и публичного сайта (`npm run build:release`) её нет совсем: ни страницы, ни ссылок, ни предпросмотра непроверенного. PIN один — владельца; его хеш PBKDF2-SHA256 с солью хранится вне репозитория, в файле `.admin-pin`, и подставляется при сборке, задать свой PIN в приложении нельзя, после 5 неверных попыток подряд вход замедляется. Это защита от случайного входа, а не от взлома: проверка идёт в браузере. Настоящая защита общей базы — права: решения в опубликованной странице может записывать только её владелец, на сервере — роль admin и RLS. PIN владельца упоминался в переписке, поэтому лучше со временем сменить его: `node tools/admin-pin.mjs --write`.
11. **Экспорт файлов в предпросмотре-артефакте** может не скачиваться (ограничение окна); рядом всегда есть копирование текста. В браузере и в приложении скачивание работает.
    **Хранение в артефакте.** В артефакте claude.ai решения проверки и прогресс хранятся в базе самого артефакта (не в памяти браузера). Решения проверки может сохранять только владелец артефакта. Пока решения живут в базе демо, в сборку для магазинов они попадают через `content/review/decisions.json` (переносит Claude) или через публикацию в Supabase.
12. **Типизация** проверялась сборщиком esbuild; полная проверка `tsc` с официальными типами React — после `npm install` на вашем компьютере.
13. **Классификация конспекта «Оптика».** По ТЗ его начало (колебательный контур, стр. o01) отнесено к электродинамике, фотон и фотоэффект — к квантовой физике; релятивистская физика временно в разделе «Оптика» (в ТЗ ей места нет). Переносится в админ-панели, раздел «Структура».
14. **Пробелы в конспектах** (интерференционный минимум o05, шкала электромагнитных волн e28, резонанс в цепи RLC e26, шунт c28, соединение проводников c27, средняя скорость 6R, плотность керосина 21L, второй постулат Бора a02, радиация a07, статика) по просьбе владельца от 20.10.2026 заполнены материалом из интернета: Википедия, «Открытая физика» (physics.ru), Большая российская энциклопедия, МЧС России, ЕГЭ-Study, справочник С. Степанова. 22.10.2026 статика расширена (рода рычагов, системы рычагов, блоки и полиспаст, наклонная плоскость, ворот, КПД, центр тяжести, сложные задачи) по ЕГЭ-Study, Skysmart, «Фоксфорд», БРЭ, Википедии, учебнику физики 9 класса (eior.by) и «Открытой физике»; на странице ЕГЭ-Study формула КПД наклонной плоскости напечатана без «1 +» в знаменателе — в приложении записан вариант, выведенный из выкладок той же страницы. Тема «Дифракция» (o07) теперь записана по вашим фото d01–d02; из интернета в ней осталось два дополнения (вторичные волны, белый свет в решётке). Это не текст конспекта: записи помечены «из интернета», под каждой — ссылки, и всё ждёт утверждения. Некоторые страницы-источники во время работы не открылись (формулы-картинки, ошибки сайта); для них приведены только данные, подтверждённые другими открытыми страницами или выведенные из формул конспекта.
15. **Анимированные рисунки** — это SVG-анимации, а не файлы GIF: они чётче, легче (все 139 — около 1 МБ), работают без интернета и меняют цвета в тёмной теме. Они не взяты из конспекта, а оживляют его рисунки и формулы: значения движения посчитаны по формулам конспекта, а числа на рисунках — из его примеров или подобраны для наглядности (например, 20 °C и 80 °C для температуры смеси, n = 1,5 для стекла); новых правил и фактов рисунки не добавляют; проверяются вместе с блоком теории (изменение рисунка снова отправляет блок на проверку). При публикации в Supabase рисунки пока не передаются — в серверной схеме для них нет поля. Так же пока не передаются поля замечаний «к чему» и «что нужно от вас» (в таблице `errata` есть только оригинал, проблема и предложение).
16. **Конспект «Магнетизм»:** начало темы о диоде нашлось в конспекте «Электричество» (стр. c40) и объединено с e01; шкала электромагнитных волн (e28) и условие резонанса для цепи RLC (e26) дополнены из интернета (замечания EM11, EM14).

## Математика (с 24.10.2026)

17. **Курс математики наполнен полностью, но не утверждён.** Все 131 пункт оглавления (главы 1.1–1.18 и 3.1–3.13) наполнены теорией, формулами, разобранными примерами и заданиями, составленными по открытым источникам; задания книги не копируются. Этап «проверено» у темы означает, что ответы пересчитаны независимым выражением, а утверждения теории проверены перебором или численно в `tests/unit/math.test.ts`; это не замена проверки преподавателем. «Утверждено» ставит только администратор — новые записи (после 1.14) пока на проверке. В пункте 3.13.5 книга даёт только разные задачи без новой теории — в приложении там сводка способов решения. Ответы с π спрашиваются как коэффициент при π (например, V/π), а не текстом «45π».
18. **Задания книги не перенесены.** Сборник защищён авторским правом, поэтому все задачи и вопросы в приложении составлены по материалам тем (это отмечено под каждым заданием), а у темы указаны страницы книги, где решать её задания. Изображения страниц книги в приложение тоже не встраиваются. Если у вас есть право использовать задания книги (например, разрешение издателя), их можно добавить отдельно с пометкой источника.
19. **Распознавание книги.** Сканы без текстового слоя; оглавление извлечено Tesseract (русский язык) и сверено глазами по изображениям. В книге геометрия пронумерована 3.1–3.13 (главы 2 нет), первый заголовок напечатан как «1 Угол. Расстояние.»; в оглавлении глава «Прямоугольник», в тексте — «Четырёхугольники». Эти места помечены в структуре курса.
20. **Источники.** Ссылки на открытые учебники и материалы университетов проверены 24.10.2026. Часть страниц открывалась не целиком — у таких источников указано, что именно использовано. Русская Википедия из среды разработки не открывалась, поэтому в источниках её нет.
21. **Проверка ответов.** Числовые ответы проверяются с допуском, запятая и точка принимаются. Сравнение алгебраических выражений на эквивалентность (ввод формулы как ответа) **не реализовано** — в математике используются задания с выбором ответа и числовым ответом.
22. **Синхронизация через Supabase** (не подключён) написана с учётом двух предметов: строки разделяются по префиксу ID `ma-`, публикация — по столбцу `subject`. На живом Supabase не проверялась; миграции и RLS проверены на PostgreSQL 16.
23. **Сборка Android не запускалась.** В среде разработки закрыт доступ к Google Maven, Android SDK и Gradle, поэтому проект Android создаётся и собирается скриптом `tools/android/build-android.ps1` на компьютере владельца. Скрипт проверен только синтаксическим анализатором PowerShell 7.6 и сверкой с шаблоном Capacitor 8.5.3 (версии SDK, имена файлов сборки, параметры `cap build`); первый запуск на Windows — первая настоящая проверка. Иконки и заставка (`assets/`) сделаны и просмотрены, но на устройстве не проверены. В приложении Android файл экспорта (прогресс, резервная копия) может не сохраниться из-за ограничений WebView — рядом есть «Скопировать».
24. **Релизная база — снимок.** В сборку для магазинов входят решения админ-панели на момент снимка (`content/release/overlays/`, 27.10.2026). Решения, принятые позже, попадут в приложение только после нового снимка и новой сборки (или через публикацию на сервер, когда подключён Supabase).
25. **Замечания к конспекту видны только в админ-панели.** Студенты видят записи физики без пометок: по принятому замечанию — исправленный текст, по оставленному — текст конспекта; служебные заметки («Замечание к странице…», «Почему тема дополнена», «запись не закончена») скрыты. Тексты для студентов — в `content/student/physics.yaml` (134 записи, из них 11 скрыты, и 26 обозначений); исходные записи конспекта не изменены и показываются администратору в очереди проверки («Что изменено для студентов»). Изменённые записи снова на проверке — до утверждения их нет в сборке для магазинов. Если решение по замечанию изменится, текст для студентов нужно обновить вручную.
26. **Фото конспектов не в репозитории.** В публичном репозитории нет фотографий страниц конспектов (только список `content/pages/pages.txt`); без них приложение собирается и работает, на экране страницы конспекта вместо фото — пояснение. Расшифровки конспектов (`content/transcript/`) и учебная база опубликованы.
