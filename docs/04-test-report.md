## Электричество: контрольные примеры

Пересчитаны примеры конспекта: заряды атома кислорода и шариков после соприкосновения (c02); $k = \frac{1}{4\pi\varepsilon_0} \approx 9\cdot10^9$ и радиус шара ёмкостью 1 Ф (c14); смешанные соединения конденсаторов $\frac{3C}{2}$, $\frac{11C}{6}$, $\frac{2C}{3}$, $2C$ (c18; «ромб» дополнительно пересчитан методом узловых потенциалов); схема с ключом $\frac{4C}{3} \to \frac{3C}{2}$, в $\frac98$ раза (c20); лампы 100 и 25 Вт последовательно — 4 и 16 Вт (формулы c31 совпадают с $I^2R$). Проверена согласованность формул: $E_0 = \frac{kq}{R^2} = \frac{\sigma}{\varepsilon_0}$ и $\varphi_0 = \frac{\sigma R}{\varepsilon_0}$ для сферы; суперпозиция через $\cos\alpha$ совпадает с векторным сложением; $A = Eqd = qU$ и закон сохранения энергии; заряды и общий потенциал после контакта шаров; $U_i = U\frac{C_{об}}{C_i}$; три формы энергии конденсатора и плотности энергии; $I = \frac qt = ne\upsilon S$; $q = \bar I\Delta t$ при линейном токе (численный интеграл); мост Уитстона — при $R_1R_4 = R_2R_3$ ток через $R_5$ равен нулю при любом $R_5$ (решение уравнений Кирхгофа); формулы чайников из $Q = \frac{U^2}{R}t$; максимум полезной мощности при $R = r$ (перебор); ЭДС параллельных источников — по узловому расчёту, в том числе при обратном включении. Тесты подтверждают замечания EL03 ($\frac{\sigma}{2\varepsilon_0}$ — одна плоскость), EL04 (пар $\frac{n(n-1)}{2}$), EL05 (не произведение), EL09 (нужна степень −1) и EL12 (атомная масса в кг/моль).

## Атомная и ядерная физика и дополнения из интернета: контрольные примеры

Пересчитаны примеры конспекта: состав $^{39}_{19}K$ (20 нейтронов), ядро из 3p + 4n ($A = 7$, $q = 3e$), сохранение A и Z в реакции с торием-232 (найденное ядро $Z = 8$, $A = 47$ — см. замечание AT10). Проверено: сдвиги при α-, β⁻-, β⁺-распаде (цепочка U-238 → α → 2β⁻ → U-234); закон $N = N_0\cdot2^{-t/T}$ совпадает с $N_0e^{-\lambda t}$ при $\lambda = \frac{\ln2}{T}$, активность $A = -\frac{dN}{dt} = \lambda N = \frac{N_0}{T}2^{-t/T}\ln2$ (численная производная), $\tau = \frac{T}{\ln2} = \frac1\lambda$. Для дополнений из интернета: уровни водорода $-\frac{13{,}6}{n^2}$ эВ согласуются с формулой Ридберга ($hR = 13{,}6$ эВ, переход 3 → 2 — 1,89 эВ, ≈ 656 нм); правило моментов; решётка $d\sin\varphi = k\lambda$ (красный отклоняется сильнее, $k_{max} = 3$ для 2 мкм и 600 нм); минимум интерференции даёт $|A_1 - A_2|$ (численное сложение волн); максимум тока RLC при $\omega_0 = 1/\sqrt{LC}$ (перебор частот); шунт и добавочное сопротивление делят ток и напряжение в n раз; средняя скорость $\frac{\upsilon_0 + \upsilon}{2} = \frac St$; керосин 800 кг/м³ даёт ≈ 12,9 м.

## Дифракция (фото d01–d02) и статика (из интернета): контрольные примеры

Дифракция: проверено, что $\sin\varphi = \frac{x}{\sqrt{L^2 + x^2}}$ — тот же угол, что $\text{tg}\,\varphi = \frac xL$, и что $d\cdot\frac{x}{\sqrt{L^2+x^2}} = k\lambda$ даёт положение максимума; $K = \left[\frac d\lambda\right]$ и $N = 2\left[\frac d\lambda\right] + 1$ верны, пока $\frac d\lambda$ не целое; при $\frac d\lambda = 5$ видно 9 максимумов, а формула даёт 11 — это подтверждает замечание DF03. Статика: рычаг с собственным весом (стержень 1 м, 2 кг → груз 4/3 кг), система двух рычагов (выигрыш 5 · 3, сила 60 Н), блоки и полиспаст ($F\cdot s = P\cdot h$ для n = 1, 2, 4, 6; подвижный блок как рычаг с плечами 2r и r), наклонная плоскость ($\eta = 80\%$; с трением $\eta = \frac{1}{1 + \mu\,\text{ctg}\,\alpha}$ совпадает с $\frac{A_{пол}}{A_{полн}}$ — формула на странице-источнике без «1 +» неверна, в приложении исправлена), центр масс (0,6 м; (2; 1); опрокидывание при $\text{tg}\,\alpha = \frac{a}{2h_c}$ ≈ 18,4°), балка на двух опорах (2000 и 1000 Н), стержень на шарнире (T = 100 Н), лестница у гладкой стены ($\mu \ge \frac{1}{2\,\text{tg}\,\alpha}$ ≈ 0,29 при 60°).

## Магнетизм, колебания, переменный ток: контрольные примеры

Пересчитаны мини-примеры конспекта: $R_{об} = \frac{2R}{3}$ и $2R$ для схем с диодом (e01), $a = 0$ при $t = 2$ (e10), $\upsilon = 4\cos\frac\pi3 = 2$ (e11), $\lambda = 15$ м (e14). Все семь рисунков направления силы Ампера на стр. e06 и направление силы Лоренца на рисунке e08 сверены с векторным произведением — совпадают. Проверено численно: $\upsilon = x'$, $a = \upsilon'$, $a = -\omega^2x$ для трёх начальных условий; $E_к + E_п = \text{const}$ и удвоенная частота энергии; формулы радиуса, периода и шага спирали частицы; $\Phi = LI = NBS$ для соленоида; $I = q'$ и сохранение энергии в контуре при $\omega = \frac{1}{\sqrt{LC}}$; $\varepsilon = -N\Phi'$ для генератора; $U_{эф} = \frac{U_0}{\sqrt2}$ как среднеквадратичное; сдвиги фаз на C и L и нулевая средняя мощность; мощность в цепи RLC; соотношения трансформатора. Тесты подтверждают замечания EM04 (потерян минус), EM09 ($\frac{\Phi^2}{LI}$ — это поток, не энергия) и EM10 (в Z потерян корень).
